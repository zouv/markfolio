# 01 · 技术栈说明

MarkFolio 使用 Tauri 2 + Rust + React 18/TypeScript/Vite。Windows 复用系统 WebView2；Rust 管理原文件、目录授权、监听、菜单和本地服务。Markdown 文件是正文来源，SQLite 仅保存可删除重建的搜索索引。

| 技术 | 用途 |
|---|---|
| Tauri 与单实例/深链/托盘/全局快捷键/通知插件 | 原生窗口、菜单、系统入口及提醒 |
| React、Zustand、TypeScript | 界面、独立工作目录会话与 IPC 类型契约 |
| CodeMirror 6、Vim/Emacs 扩展 | Markdown 编辑、撤销、查找与就地预览 |
| markdown-it、Turndown、DOMPurify、YAML | 渲染、HTML 转换、净化和保留式属性修改 |
| KaTeX、Mermaid、highlight.js、abcjs、fountain-js | 公式、图表、代码、乐谱与剧本 |
| PDF.js、Tesseract.js 与中英文模型 | 本地 PDF 阅读和离线 OCR；Worker/字体/模型随包提供 |
| rfd、notify、rusqlite、sha2、tempfile、trash | 目录授权、监听、增量检索、版本检测、原子保存、回收站 |
| htmd、quick-xml、tar、zip、one2html、onenote_parser | HTML/ENEX/JEX/RAW/OneNote 与资源转换 |
| AES-GCM、Argon2、keyring、reqwest | 本地密码加密、系统凭据与显式配置的网络服务 |
| node:test、cargo test/fmt/clippy、Playwright | 契约、真实文件/服务、质量与独立界面检查 |

开发启动 Vite 后编译 Rust，生产将前端和本地资源打包进应用。原生访问统一经 src/api.ts，命令声明/注册/封装由契约测试核对。保存比较磁盘内容摘要，用同目录临时文件原子替换，不保留旧版本。文件通知驱动增量索引和冲突处理，跨窗口设置按字段合并。

插件默认在不透明 iframe 内的 Worker 执行，仅通过 SDK 消息桥访问宿主；Rust 再校验目录和文件权限。可信模式用于直接操作 DOM/CodeMirror，需要完整宿主授权。

版本唯一来源 Cargo.toml；标识、窗口、CSP 和开发端口在 tauri.conf.json。生产不允许通用 eval/inline 脚本；专用 WebAssembly 许可用于 OCR/PDF。scripts/third-party.mjs 从锁文件收集许可/署名、字体/OCR 声明和相关组件源码，随安装与免安装包提供；自有代码未自行选择公开许可证。

Windows 构建需要 Rust、MSVC Build Tools、WebView2；macOS 需要 Xcode Command Line Tools；Linux 需要 WebKitGTK 4.1、GTK 3 和托盘系统库。当前原生交付针对 Windows。统一命令见 [README](../README.md)，代码路由见 [ARCHITECTURE](../ARCHITECTURE.md)。
