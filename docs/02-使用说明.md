# 02 · 使用说明

## 开始使用

Windows 打包后可直接运行 dist/release/unpack/markfolio.exe，也可运行 MSI 或 NSIS 安装包。需要 WebView2 Runtime，安装器会在缺少时提供运行环境。

1. 点击“打开工作目录”，选择保存 Markdown 的文件夹，不需要先导入文档。
2. 使用顶部加号再打开一个目录，点击页签切换；Ctrl+Tab / Ctrl+Shift+Tab 切换目录。
3. 左侧显示真实文件树，中间是当前目录中的文档，右侧是编辑器和预览。单击目录显示列表，展开箭头显示子目录。
4. 新建笔记与文件夹会直接写到选中的目录。双击文档标题或 F2 重命名；文件树右键可移动、重命名或移入回收站。
5. 从文件菜单、格式工具栏、命令面板和设置访问相关功能。Ctrl+Shift+P 打开命令面板。

## 多选、复制和设置

在中间文档列表按 Ctrl 单击可增减选择，Shift 单击选择从锚点到当前项的范围。列表获得焦点时 Ctrl+A 全选；顶部选择栏和右键菜单提供批量移动、删除和复制笔记。复制默认 Ctrl+D，副本保存在原文件夹，名称自动附加“副本”，已有文件不会被覆盖。

移动或复制会先保存受影响笔记。删除时含未保存编辑的项目会跳过，其他项目继续处理；结束后提示成功与失败项。处理期间该工作目录暂时不能编辑或关闭，可以切换其他工作目录。

设置左侧可搜索选项。“应用”保存并立即生效，窗口保持打开；“确定”保存并关闭；“取消”或关闭窗口丢弃尚未应用的修改。已经应用的修改仍保留。插件安装立即执行，插件启停及配置修改需应用后生效。

“键盘快捷键”支持点击输入框后按组合键，或粘贴组合键文字；清空取消绑定，“重置”恢复默认。重复绑定或系统保留按键会显示原因并阻止应用。当前工作目录插件命令也可设置快捷键；Ctrl+Tab / Ctrl+Shift+Tab 始终用于切换工作目录。

## 保存与文件

- 默认停止输入约 1.2 秒后自动保存，也可 Ctrl+S 手动保存；设置里可以关闭自动保存或调整延迟。
- 文档标题来自文件名，正文一级标题可以不同。应用不自动添加 ID 或 front matter。
- 支持 UTF-8、UTF-8 BOM 与有 BOM 的 UTF-16 LE/BE。编辑器内部统一显示 LF，保存恢复文档原有的换行类型与支持的编码。
- 单篇文件上限 16 MB；图片/PDF 读取接口上限 32 MB。其他编码或超大文件可用系统编辑器处理。
- 外部程序修改已打开文件后，无未保存内容的缓冲会刷新；有未保存内容时暂停自动保存，点击“比较与处理”选择要保留的版本。
- 关闭工作目录或退出时尝试保存。如果保存失败，保持窗口并提示处理，避免无提示丢弃编辑。
- 工作目录关闭不会删除文件。重新选择同一路径会复用目录身份和插件配置；退出后恢复仍打开的目录。
- 移动或重命名目前不会自动重写其他文档的链接。工作目录不允许互相嵌套；文件访问限制在所选根内。

## 预览、附件与搜索

可切换仅编辑、并排与仅预览。支持表格、可勾选任务、代码高亮、脚注、KaTeX 和 Mermaid。任务勾选修改对应 Markdown 行，并沿用正常保存规则。

附件按钮通过原生文件选择器复制文件到当前文档所在目录，同名时使用新名称；文档中插入相对链接。图片从本地目录加载，远程图片不自动请求。非 Markdown 附件交给系统程序。首次打开外部 HTTPS 网站需允许该主机，之后交给系统浏览器。

搜索覆盖当前工作目录中 Markdown 文件的名称和正文。空格分隔多个词，结果需要包含所有词；中文短词可检索。隐藏目录不参与索引，最多返回 200 条；索引可在工具菜单重建。当前使用子串匹配，超大目录的增量优化尚未完成。

文件菜单“打印 / 导出 PDF”打开系统打印流程，可选择打印到 PDF；尚未进行本机打印界面验收。

## 插件

内置每日笔记、Markdown 工具和统计面板。启用状态及插件数据按工作目录保存。在设置的“插件”页选择包含 manifest.json 和 main.js 的目录安装可信插件，安装后在目标工作目录启用。

阅读时间示例位于 examples/plugins/reading-time。当前 SDK 支持自包含 ESM；原始 Obsidian 插件需要按 [04-插件开发.md](04-插件开发.md) 移植。

## 数据位置

正文与附件一直在用户选择的目录。应用设置、已打开目录记录、插件代码及检索索引在系统应用数据目录；Windows 通常为 %APPDATA%/dev.markfolio.app。

state.json 保存配置；indexes/ 保存可重建索引；plugins/ 保存本地安装的插件。不生成持久文件历史或自动备份。会话内撤销和导航后退仍属于编辑操作。

## 开发、检查与打包

| 任务 | 统一入口 |
|---|---|
| 安装依赖 | sh manager.sh setup |
| 原生开发 | sh manager.sh dev |
| 浏览器界面预览，无文件 IPC | sh manager.sh web |
| 类型、前端契约/行为、Rust 文件测试 | sh manager.sh test |
| 合成界面的多选、设置与快捷键交互 | sh manager.sh test-ui |
| 格式、clippy、类型检查 | sh manager.sh check |
| Windows / 当前平台打包 | sh manager.sh package |
| 文档检查 | sh manager.sh check-docs |

Windows 可双击根目录的 setup/dev/build/test/package.bat。构建前置条件见 README 和技术栈说明。

打包输出 dist/dev 的 Debug zip，dist/release 的安装器、unpack/、Release zip、SHA256SUMS.txt 和文件清单。使用 package --skip-build 可重新收集已编译产物；源码改变后应完整打包。

图标源是 assets/markfolio.svg / markfolio.png；用 npm run tauri icon assets/markfolio.png 重新生成图标。

## 常见问题与当前限制

- 浏览器预览不能选真实工作目录；完整功能运行桌面版。
- 开发窗口空白时检查 WebView2 和开发服务，开发端口读取 tauri.conf.json 的 devUrl。
- 文件无法保存时检查权限、是否被移动和磁盘空间；冲突时先比较内容，其他暂时错误可手动重试保存。
- 首次 Rust 编译及安装器工具下载较慢；后续增量构建更快。
- 自动文件/状态测试与独立 Chrome 合成界面测试通过；原生文件选择、回收站、菜单加速键和插件安装等完整桌面验收仍未完成。具体待补功能见 ROADMAP，不把当前版本视作完整 Joplin 复刻。
