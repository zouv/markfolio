# 02 · 使用说明

## 打开目录与编辑

运行免安装包的 MarkFolio.exe，或安装 MSI/NSIS 后打开。点击“打开工作目录”选择现有文件夹，顶部加号打开更多目录，Ctrl+Tab / Ctrl+Shift+Tab 切换。工作目录页签在自绘标题栏中，可拖动排序、悬停关闭或右键新增；左上角应用图标提供设置、关于和退出，右侧是最小化/最大化/关闭。各目录保留笔记、选择、导航和插件配置，原文件无需导入数据库。

打开文档后，文件页签栏位于文件列表与编辑器顶部，可点击切换、悬停关闭或右键关闭其他/全部标签。未打开文档时可在页签栏直接快速搜索。快捷键由命令系统统一处理，可在设置中查看和修改；原生菜单栏已由应用图标菜单替代。应用菜单的“关于 MarkFolio…”展示当前版本与用途说明，第三方许可证与资源在独立窗口中打开。

左侧是真实文件树，中间可选择当前目录、全部笔记、待办、标签或搜索结果，右侧可仅编辑、并排或仅预览。设置可调整主题、面板顺序/大小、字体、缩放和列表样式；Ctrl+Shift+P 打开命令面板。

默认停止输入 1.2 秒自动保存，Ctrl+S 手动保存。支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE，并保留 LF/CRLF；单篇限制 16 MB，附件读取限制 32 MB。普通文件不自动插入 ID 或属性。外部修改与未保存编辑冲突时暂停自动保存，打开“比较与处理”。关闭目录/窗口或退出会先处理保存，失败时保留编辑。关闭目录不删除文件；工作目录不能互相嵌套。

## 文件、列表与属性

新建、重命名、移动对应实际文件操作。Ctrl 单击增减选择，Shift 单击范围选择，列表 Ctrl+A 全选。复制自动生成不冲突名称；移动/复制先保存受影响笔记，删除跳过未保存项并汇报部分失败。默认使用 .markfolio/trash 应用垃圾箱，可恢复原位置且不覆盖同名；也可设置为系统回收站。

可按名称、修改/创建时间、大小或手动顺序排序并反转；“按目录独立记住排序”恢复各目录选择，文件夹可另按名称/修改时间排序。属性窗口可编辑标题、标签、别名、待办/完成、提醒、来源和置顶，写入 Front Matter，保留未知 YAML 和正文。待办支持完成过滤、未完成置顶和运行期间到期提醒；系统通知依赖系统设置。

## Markdown 与富文本

源码编辑提供撤销/重做、查找替换、格式、行移动/复制/删除/排序、注释/缩进和表格行列菜单。表格菜单作用于当前单元格，保留表格外正文；不能删除表头/分隔行或最后一列。

富文本按段落、列表、引用、表格编辑，与源码共用撤销。特殊/未知语法保留源码，可双击或点击“源码”编辑；改动普通块会规范化该块 Markdown，要求完全保留排版时使用源码编辑。

直接粘贴图片会保存本地附件并插入相对引用；HTML 可转换为 Markdown，也可粘贴纯文本。异步生成和附件插入绑定原笔记选区；选区失效会提示，AI 结果保留。设置支持 Vim/Emacs、系统拼写检查、图片/公式就地预览、预览字体/宽度和自定义 CSS。

扩展开关控制脚注、高亮、上下标、定义列表、缩写、插入、多行表格、自动目录、ABC 和 Fountain。使用 [toc] 自动生成目录，abc/fountain 代码块呈现乐谱/剧本。任务勾选更新对应源码行。

## 链接、检索与媒体

相对链接及 [[笔记#标题|显示文字]] 在当前目录解析，同名候选可选择。Ctrl+P 快速搜索所有已打开工作目录的标题、路径、别名和标签；输入 #标题 可跳转，Enter 打开。移动/重命名默认维护入链与出链，代码块里的示例保持原样。文件菜单可复制 markfolio://open 应用外链接，或在独立笔记窗口打开。

检索限制在当前工作目录，支持中文短词、双引号短语、* 通配、- 排除、OR 和 any:1。常用语法：

| 示例 | 用途 |
|---|---|
| title:方案 tag:work | 标题与标签都匹配 |
| "项目计划" -body:废弃 | 短语匹配并排除正文词 |
| path:docs/* OR title:会议 | 路径或标题 |
| type:todo is:uncompleted | 未完成待办 |
| created:>=2026-01-01 updated:day-7 | 创建时间与最近七天更新 |
| due:<day1 | 日期早于明天 |

还支持 body、notebook（目录）、source。索引按事件增量更新且可重建，设置可限制缓存体量和已保存缓冲数量；单次最多显示 200 条结果。

附件管理器显示引用位置，可插入/清理。图片可缩放，PDF 可翻页/缩放，音视频本地播放。远程图片默认不自动下载，可开启后手动加载。外部 HTTPS 网站经允许后交给系统浏览器。

## 导入导出与桌面功能

工具菜单支持 JEX/RAW、ENEX、HTML/ZIP、OneNote .one/.onetoc2/.onepkg 或其 HTML 导出：先预览，再导入新文件夹，迁移可识别属性、资源和链接。原文件保留。

可导出选中/全部笔记为 Markdown、HTML、PDF；Markdown 附带引用资源，HTML/PDF 嵌入本地媒体、字体、图表，不隐式包含未选笔记正文。PDF 转换使用本机 Edge/Chrome，“打印”使用系统打印流程。可选择外部编辑器并开始/停止会话，磁盘改动沿用冲突检测。

OCR 使用随包中英文模型在本机识别。白板支持画笔/形状/文字、撤销/重做，保存 JSON/SVG 并插入笔记，关闭提示未保存修改。本地锁定把笔记转为 .mflock，不索引加密正文；解密恢复编码/换行，需保管密码。

托盘与全局唤起默认 Ctrl+Alt+M，可配置关闭主窗口到托盘。更新服务需填写自己的 HTTPS 清单（version/url/sha256/notes），下载校验后启动安装。没有替用户建立公共发布服务。

## AI、API/MCP 与剪藏

AI 写作助手填写完整 Chat Completions 地址和模型；本机 HTTP 服务可不填密钥，远程服务使用 HTTPS。密钥在系统凭据库按完整服务地址隔离。勾选上下文才发送当前选区/笔记，结果可编辑并插入原选区。

本地 API 仅监听 127.0.0.1，绑定启动时工作目录，默认只读。启用写入后可写笔记和剪藏。每次请求需 Authorization: Bearer 访问令牌；停止或关闭目录令牌失效。

读取：GET /notes、POST /read（path）、POST /search（query）；写入：POST /write（path/text/expectedVersion），旧版本返回冲突。MCP 地址 /mcp，支持 HTTP JSON 和 list_notes/read_note/search_notes/write_note 工具。

browser-extension/ 是 Chrome/Edge Manifest V3 扩展，加载解压目录后填写本地地址/令牌，可把选区/文章保存为 Clippings/ 下 Markdown 并保留来源。重启服务需更新令牌；默认不下载网页远程资源。

## 插件、设置与交付

插件安装后检查目标工作目录权限并启用；启停/配置在应用后生效，安装/卸载立即执行。安全模式暂停所有插件。SDK、示例和移植见 [插件开发](04-插件开发.md)。

设置可搜索、应用/确定/取消；取消仅丢弃未应用草稿。快捷键可编辑、清空、重置、JSON 导入导出；冲突会阻止应用，插件命令使用相同系统。

Windows 配置位于 %APPDATA%/dev.markfolio.app 的 state.json、plugins/、indexes/；正文仍在原目录。安装/免安装包包含文档、示例、剪藏及第三方声明，“关于”可查看许可证。软件不提供同步、持久文件历史或自动备份。

开发统一入口见 [README](../README.md)，验收状态见 [ROADMAP](../ROADMAP.md)。
