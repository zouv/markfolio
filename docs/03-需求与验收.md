# 03 · 需求与验收

以 Joplin 为界面和交互参照，以 Obsidian 的本地文件目录模型为数据基础。使用 Tauri 2 + Rust + React，保留真实文件树、直接 Markdown 编辑、多工作目录同时打开和页签切换。同步、云分享、持久文件历史、自动备份不开发。

| 范围 | 完成判据 |
|---|---|
| 多目录 | 双目录同时打开、切换恢复会话、同名不串写、关闭不删除 |
| 保存与文件 | 原文件/编码/换行、原子替换、冲突保留、越界拒绝 |
| 管理与布局 | 三栏/菜单/焦点/快捷键、多选/复制/移动/排序、垃圾箱恢复、设置应用/取消 |
| 编辑渲染 | Markdown/分块富文本、撤销、HTML/图片粘贴、表格行列与扩展开关 |
| 属性搜索 | 未知 YAML 保留、标签/待办/提醒/置顶、字段/日期/OR/排除、增量检索 |
| 链接媒体 | 同名选择/标题跳转、移动链接维护、图片/PDF/音视频/附件 |
| 转换导出 | JEX/RAW/ENEX/HTML/真实 OneNote、资源/元数据/链接、独立 HTML/真实 PDF |
| 插件 | 默认隔离、逐请求权限、目录独立数据、安装/卸载回退与异步清理 |
| 本地工具 | 离线 OCR、画板、密码认证、本机 AI、API/MCP 认证/冲突/生命周期 |
| 桌面交付 | 原生目录/菜单/保存/多窗口、自动/界面检查、当前版本包与 SHA-256 |

自动检查使用合成目录/本机服务；真实 OneNote/PDF 样本由环境变量指定。界面使用独立 Chrome，不读取个人浏览器配置；桌面验收仅操作 .runtime/ 的合成文档。原生操作与自动结果分别记录，实际状态见 [ROADMAP](../ROADMAP.md)。

Windows 交付包括 Release/Debug、MSI/NSIS、免安装 zip、清单、校验和使用说明/插件示例/剪藏/许可。AI 服务、更新清单、插件仓库和具体第三方插件源码需用户提供。其他平台/其他语言/具体第三方插件属于后续新增范围；Obsidian 插件没有直接兼容层。
