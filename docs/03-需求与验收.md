# 03 · 需求与验收

## 产品定位

MarkFolio 是自用的本地 Markdown 文档管理工具。技术栈为 Tauri 2 + Rust + React；界面和交互参考 Joplin，数据直接面向本地文件目录。

## 已确定差异

1. 移除文件同步、持久历史记录和自动备份，只管理本地文件。
2. 多个工作目录可以同时打开，以顶层页签切换；每个目录保持独立会话。
3. 左栏显示真实目录与文件，直接编辑 Markdown，不先导入数据库。

## 界面约定

- 顶部菜单、工具栏和工作区页签；左侧文件树，中间当前目录列表 / 检索结果，右侧编辑 / 预览。
- 可隐藏列表、侧栏；可调整面板大小；保留编辑、预览、并排模式。
- 文件名与正文标题分离；新建、重命名、移动必须对应实际文件操作。

## 验收矩阵

| 类别 | 必须验证 |
|---|---|
| 工作区 | 双目录打开、切换状态恢复、重复目录激活、关闭不删除文件 |
| 文件 | 中文路径、新建、移动、重命名、删除、嵌套目录、越界拒绝 |
| 编辑 | 原文件内容、撤销、查找、自动保存、关闭处理、外部修改冲突 |
| 渲染 | 表格、代码、任务列表、公式、链接、图片、本地附件 |
| 检索 | 中文短查询、标题、正文、标签、工作区范围 |
| 插件 | 安装、启停、清理、设置持久化、异步任务绑定原工作区 |
| 发布 | fmt、clippy、类型检查、契约/行为测试、桌面操作、打包 |

## 保留范围的后续核对

富文本、待办提醒、OCR、白板、本地锁定、AI/MCP、导入格式与旧插件兼容需要独立实现与验收；没有实现的入口不得冒充已完成。详细完成状态见 ROADMAP。

## 非目标

不提供同步目标、远端账号、云端分享、历史版本和自动备份；不承诺未修改的 Obsidian 插件直接运行。用户选定插件源码后检查许可证并逐项移植。
