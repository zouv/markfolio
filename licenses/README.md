# 第三方许可来源

`overrides/` 保存上游发布包未附带或资源单独需要的许可全文。每份文件的原始来源记在 `overrides/sources.json`；这些文件保持原样。

`scripts/third-party.mjs` 根据锁文件和本机 Rust 构建目标收集直接/间接依赖声明、版权、字体声明，以及 MPL/EPL 组件的当前包源码。输出 `public/third-party/` 是生成资源，不入库；构建时嵌入应用并作为安装器资源，免安装包同样带上完整目录。

项目自有代码未选择公开发布许可证。Obsidian/Joplin 插件不能直接安装；移植具体插件时，需要检查该插件及其依赖的授权，并补齐相应声明。
